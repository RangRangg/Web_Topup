## 🌟 Deskripsi Aplikasi & Fitur Kecerdasan Artifisial (Aethereal AI)

**Aethereal Joki** adalah platform web modern bertema *futuristic dark gaming marketplace* yang dirancang khusus untuk memprofesionalkan talenta gamers mandiri (UMKM jasa joki game) serta menyediakan layanan top-up game instan berkeamanan tinggi.

### Fitur Strategis Kecerdasan Artifisial (**Aethereal AI**):
1. **Arsitektur Dual-Engine**: Terintegrasi langsung dengan Upstream Generative Cloud LLM (NVIDIA NIM AI / Google Gemini API) serta diperkuat oleh *Deterministic Context-Grounded Intelligent Fallback Engine* untuk menjamin ketersediaan 100% (*zero-crash*).
2. **Retrieval-Augmented Generation (RAG) Grounding**: Menggali data riil dari database relasional toko (harga produk, promo aktif, status pesanan, testimoni pelanggan) sehingga jawaban AI faktual dan bebas halusinasi.
3. **Strict Security Guardrails**: Membatasi lingkup AI hanya pada ekosistem web dan game (menolak pembuatan kode Python) serta menyesuaikan identitas pengguna secara personal berdasarkan sesi login aktif.
4. **Fast-Path Dynamic Resolution**: Menjawab pertanyaan cepat seperti identitas diri, statistik pelanggan, dan jumlah booster dalam < 100 ms tanpa membebani kuota API.

## 🚀 Panduan Instalasi Langkah Demi Langkah di Laragon

Ikuti 15 langkah berikut secara berurutan untuk menyiapkan dan menjalankan Aethereal Joki:

### 1. Install Laragon
Jika belum memiliki Laragon, unduh dan install **Laragon Edition (Full / WAMP)** dari [https://laragon.org](https://laragon.org).

### 2. Pastikan Apache/Nginx Aktif
Buka aplikasi Laragon, klik tombol **Start All**. Pastikan service **Apache** telah berstatus berjalan (tombol Stop berwarna merah/hijau menyala).

### 3. Pastikan MySQL Aktif
Pastikan service **MySQL** telah aktif (default port `3306`).

### 4. Buat Database Bernama "Aether"
Buat database MySQL baru dengan nama `Aether`:
- **Cara GUI (HeidiSQL / phpMyAdmin):**
  1. Klik tombol **Database** di Laragon untuk membuka HeidiSQL, atau akses phpMyAdmin di `http://localhost/phpmyadmin`.
  2. Buat database baru bernama `aether` dengan collation `utf8mb4_unicode_ci`.
- **Cara Terminal Laragon:**
  Klik tombol **Terminal** di Laragon dan ketik:
  ```bash
  mysql -u root -e "CREATE DATABASE IF NOT EXISTS Aether CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"
  ```

### 5. Pastikan Project Berada di Folder Laragon
Pastikan folder project terletak di direktori www Laragon:
```text
C:\laragon\www\Aether
```
*(Atau `D:\laragon\www\Aether` jika Laragon diinstall di drive D).*

### 6. Jalankan Composer Install
Buka terminal di root project (`C:\laragon\www\Aether`) dan pasang dependensi backend PHP:
```bash
composer install
```

### 7. Jalankan NPM Install
Unduh paket pustaka frontend (Tailwind CSS v4, Vite, Alpine.js):
```bash
npm install
```

### 8. Salin .env.example Menjadi .env
Duplikasi berkas konfigurasi template:
```bash
copy .env.example .env
```
*(Atau `cp .env.example .env` pada terminal Git Bash / PowerShell).*

### 9. Konfigurasi Database & Environment
Buka file `.env` dan pastikan konfigurasi berikut telah terisi:
```dotenv
APP_NAME="Aethereal Joki"
APP_ENV=local
APP_DEBUG=true
APP_URL=http://Aether.test

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=Aether
DB_USERNAME=root
DB_PASSWORD=

SESSION_DRIVER=database
QUEUE_CONNECTION=database
CACHE_STORE=database
```

### 10. Jalankan Generate Application Key
Generate encryption key aplikasi:
```bash
php artisan key:generate
```

### 11. Jalankan Migrasi & Database Seeder
Eksekusi migrasi skema tabel serta seeder data demo:
```bash
php artisan migrate --seed
```
*(Atau `php artisan migrate:fresh --seed` jika ingin mengosongkan dan mengisi ulang database dari awal).*

### 12. Jalankan Storage Link
Buat symbolic link untuk direktori penyimpanan publik:
```bash
php artisan storage:link
```

### 13. Jalankan Kompilasi Asset Frontend
Kompilasi asset CSS dan JavaScript untuk mode produksi:
```bash
npm run build
```

### 14. Restart Laragon Jika Diperlukan
Klik kanan pada jendela Laragon > **Apache** > **Reload** atau klik **Stop All** lalu **Start All**. Hal ini memastikan modul Apache membaca konfigurasi Virtual Host dan DNS lokal yang baru.

### 15. Buka Aplikasi di Browser
Buka browser favorit Anda (Google Chrome, Microsoft Edge, Mozilla Firefox) dan kunjungi URL resmi lokal:
👉 **[http://Aether.test](http://Aether.test)**

## ⚙️ Panduan Auto Virtual Hosts & Document Root Laragon

Jika domain `http://Aether.test` tidak otomatis terdeteksi oleh Laragon:

1. **Aktifkan Fitur Auto Virtual Hosts:**
   - Klik kanan di jendela Laragon > **Preferences** (atau ikon gerigi).
   - Pada tab **General**, beri tanda centang pada opsi **Auto Virtual Hosts**.
   - Format Hostname default Laragon adalah `{name}.test`. Karena nama foldernya adalah `Aether`, Laragon otomatis menetapkan domain `Aether.test`.

2. **Memastikan Document Root Mengarah ke `/public`:**
   - Laragon secara otomatis mendeteksi struktur project Laravel dan mengarahkan document root ke subfolder `public`.
   - File konfigurasi Apache Virtual Host otomatis tersimpan di:
     `C:\laragon\etc\apache2\sites-enabled\auto.Aether.test.conf`
   - Pastikan isi file tersebut mendefinisikan direktori root ke folder `/public`:
     ```apache
     define ROOT "C:/laragon/www/Aether/public"
     define SITE "Aether.test"

     <VirtualHost *:80> 
         DocumentRoot "${ROOT}"
         ServerName ${SITE}
         ServerAlias *.${SITE}
         <Directory "${ROOT}">
             AllowOverride All
             Require all granted
         </Directory>
     </VirtualHost>
     ```

## 🛠️ Panduan Pemecahan Masalah (Troubleshooting)

### 1. `Aether.test` Tidak Bisa Dibuka / "This site can't be reached"
- **Penyebab:** Apache belum berjalan, atau entri Windows hosts belum ditambahkan.
- **Solusi:**
  1. Pastikan tombol **Start All** di Laragon aktif.
  2. Buka file `C:\Windows\System32\drivers\etc\hosts` (menggunakan Notepad Run as Administrator).
  3. Pastikan terdapat baris:
     ```text
     127.0.0.1 Aether.test
     ```
  4. Simpan file lalu reload Apache dari Laragon: klik kanan Laragon > **Apache** > **Reload**.

### 2. Database Connection Error ("SQLSTATE[HY000] [2002] Connection refused")
- **Penyebab:** Layanan MySQL Laragon belum aktif atau konfigurasi database di `.env` salah.
- **Solusi:**
  1. Pastikan MySQL di Laragon aktif (Port 3306).
  2. Periksa baris konfigurasi di file `.env`:
     ```dotenv
     DB_CONNECTION=mysql
     DB_HOST=127.0.0.1
     DB_PORT=3306
     DB_DATABASE=Aether
     DB_USERNAME=root
     DB_PASSWORD=
     ```
  3. Jalankan `php artisan config:clear`.

### 3. Error 404 Not Found Saat Mengakses Halaman Tertentu
- **Penyebab:** Modul `mod_rewrite` Apache tidak aktif atau file `public/.htaccess` hilang.
- **Solusi:**
  1. Pastikan file `public/.htaccess` ada di dalam project.
  2. Aktifkan modul rewrite: klik kanan Laragon > **Apache** > **modules** > pastikan **rewrite_module** tercentang.
  3. Pastikan directive `AllowOverride All` aktif pada konfigurasi virtual host.

### 4. Tampilan Rusak / "Unable to locate file in Vite manifest" / Vite Assets Hilang
- **Penyebab:** Aset frontend belum dikompilasi atau file manifest belum terbentuk.
- **Solusi:**
  Jalankan perintah build aset di terminal:
  ```bash
  npm run build
  ```
  *(Atau jalankan `npm run dev` jika sedang melakukan pengembangan aktif).*

### 5. Masalah Izin Berkas / Permission / Storage Issue ("The stream or file ... could not be opened")
- **Penyebab:** Folder storage atau bootstrap cache terkunci atau permission Windows terbatas.
- **Solusi:**
  Jalankan perintah pembersihan cache Laravel:
  ```bash
  php artisan optimize:clear
  ```
  Pastikan folder `storage` dan `bootstrap/cache` memiliki hak akses tulis (write permission).

### 6. "No application encryption key has been specified" (APP_KEY Missing)
- **Penyebab:** `APP_KEY` pada file `.env` kosong.
- **Solusi:**
  Jalankan perintah:
  ```bash
  php artisan key:generate
  php artisan config:clear
  ```
